🕉️ IndicWisdom AINative Android App for Multilingual Mythology & Lifestyle Q&A📖 AboutIndicWisdom is a vernacular-first AI assistant designed to answer lifestyle and Indian mythology queries. It aggregates answers from multiple LLMs (GPT-4o, Gemini, Llama) simultaneously, allowing users to compare perspectives.The app features a Voice-First Interface optimized for Indian languages (Telugu, Hindi, English), providing real-time transcription, auto-translation, and seamless social sharing.✨ Key Features🗣️ Vernacular Voice Input: Live speech-to-text transcription for Telugu & Hindi using Android SpeechRecognizer.🧠 Multi-Model Consensus: Fetches answers from Gemini 1.5 Flash, GPT-4o, and Claude 3 in parallel.🔄 Smart Translation Bridge: Automatically translates vernacular queries to English for better AI reasoning, then re-translates answers back to the user's native language.📱 Social Share Integration: One-click sharing of formatted answers to WhatsApp, Instagram, and Facebook.🔊 Native Text-to-Speech: Listen to answers in local languages.🛠️ Tech StackAndroid Client (Mobile)Language: KotlinUI Framework: Jetpack Compose (Material 3)State Management: MVVM + Hilt (Dependency model requests)Database: Firebase Firestore (User history & bookmarks)AI & ServicesTranslation: Google Cloud Translation API (Advanced)Speech-to-Text: Google Cloud Speech API + Android NativeModels: OpenAI API, Google Vertex AI, Groq API🚀 User Flow (Under the Hood)Input: User speaks in Telugu.Transcribe: App renders live text overlay ("Pandavas entha mandi?").Process: Backend translates to
